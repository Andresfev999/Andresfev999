                                     │ HTTPS (Port 443)
                     ┌───────────────▼────────────────┐
                     │   TRAEFIK REVERSE PROXY v3     │
                     │  (SSL Let's Encrypt / Router)  │
                     └───────┬──────────────┬─────────┘
                             │              │
        Path: /              │              │ Path: /apps | /erp
    ┌────────────────────────▼───┐      ┌───▼────────────────────────┐
    │   Web Corporativa (Next)   │      │   Proton Apps / ERP Suite  │

                                    │ Internal Docker Network

## 🧠 Engineering Principles

- ⚡ **PERFORMANCE:** 60 FPS • Aceleración por GPU en compositor (`transform`, `opacity`) • Cero layout shifts.
- 🛡️ **SECURITY:** Cifrado end-to-end • Consultas SQL parametrizadas • Headers de seguridad HSTS/CSP • Zero plain-text secrets.
- 🔄 **CI/CD:** Pipelines automatizados • Rolling updates sin caída • Contenedores inmutables Docker.
- 📐 **ARCHITECTURE:** Clean Architecture • Interfaces estrictas en TypeScript • Microservicios desacoplados.
